# Security Policy

### Supported Versions

Security updates are provided for the latest release on the `main` branch.

| Version | Supported |
|---|:---:|
| Latest `main` | ✅ |
| Prior tags | ❌ |

---

### Reporting a Vulnerability

If you discover a security vulnerability (such as a path traversal vulnerability, improper handle cleanup, or credential exposure), please report it responsibly:

1. **Do not** file a public issue.
2. Submit a report privately via GitHub Security Advisories or contact the maintainer directly.
3. Provide a minimal reproduction script and description of the potential impact.

Reports will be acknowledged promptly and addressed in an upcoming security release.
