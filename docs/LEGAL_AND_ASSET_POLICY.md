### 2. Zero Asset Distribution Policy
This repository strictly adheres to a clean-room asset boundary:

1. **No Game Assets**: No proprietary 3D models, Live2D geometry, MOC3 files, texture atlases, audio files, motion curves, or text assets from hololive Dreams are included in this repository.
2. **No CDN Payloads**: No downloaded remote asset bundles or cache payloads are committed to version control.
3. **No Proprietary SDK Binaries**: The proprietary Live2D Cubism Core runtime library (`live2dcubismcore.min.js`) is **not distributed** in this repository.
4. **Local Processing**: HDM acts solely as a client-side conversion tool that processes files already legally present on the user's computer via an authentic Steam purchase.
